1: RPG Maker is a basic tool used to help game devs or potential game developers create their
own RPG relatively easily. 
As expected by the name it is strictly used to create RPG’s based upon a set list given to you. 
However if you know how to code and find / create your own assets you can actually alter or enhance the basic tools given to you for your vision. 
Given its very easy usability anyone can basically just hop right in even with no coding experience thanks to RPG Maker’s event system. 
While it is true RPG Maker is easy to use, you are limited to its own library of assets and code unless you create or find the rest yourself which can be its own challenge.
While I may not personally consider this a big negative (if one at all) I can see how this might turn other people away from it if they are just trying to do something specific without knowing how to code but it is not available. The other big negative is the price of 80+ dollars which is pretty steep.
Overall I believe RPG Maker is a great starter tool for game devs to dip their toes into the world of game creation and with a strong community behind it should be tried at least once by every game developer who has any interest in creating an rpg.
https://www.rpgmakerweb.com/ 

2: Kirikiri Z, while I could not find much information on this for whatever reason, this is a game engine that allows you to create visual novels using C++.
That is essentially all it is used for and it seems to be fairly popular as well. 
The only con I can think of is that you are limited to strictly visual novels but if you are using this then that's kind of the point so I’m not sure what to put for cons. 
https://krkrz.github.io/ 

3: NcEngine is a 3D game engine using C++ that is free for use on Windows. Pros: It is still being developed even now and feedback is taken and implemented allowing for users to better enjoy the game engine / fix bugs or problems. 
Cons: It is run by only 2 people so if something goes wrong it could take a while to fix.
https://ncstudios.itch.io/ 

4: Easel is a partially free platform that lets you code multiplayer games without needing to code the multiplayer part yourself.
Pros: Easel actually teaches you how to code so you can start making games immediately and enjoy coding right away. 
Cons: Easel only lets you upload your games onto Easel so each game is strictly browser based. 
This is best used for early game projects and learning fundamentals, or improving on fundamentals.
https://easel.games/ 

5: Pyrite64 is a free visual editor and runtime engine used to create 3d games that run on N64 consoles or emulators using C++. 
A few Pros are, 3D-Model import from blender and support for big texture rendering (256x256). 
The only real con is that it is still in early development so some features might be missing. 
Definitely worth checking out for anyone interested in the N64 console or emulating it.
https://github.com/HailToDodongo/pyrite64 

6: NESmaker is an engine used to make NES games that can not only be played on an appropriate emulator but they also work with Infinite NES lives and Retro Stage to make physical copies as well. 
This is one of the more interesting ones I found because it is rare to find a game engine for older consoles that works with not only emulators but the console itself making that a very easy pro.
A con however would be the starting price point of 36$ which while isn’t the most expensive can definitely be a bit of a commitment for people currently struggling financially but really want to create an NES game.
https://www.thenew8bitheroes.com/ 

7: RPG paper maker is similar to RPG maker but as suggested by the name specifically uses “paper”. 
RPG paper maker specifically uses 2d sprites with 3d objects to give your game rather unique visuals. 
A negative I found was that you cannot publish your games to consoles and it is strictly PC based, but of the PC OS’s it does cover basically all of them, allowing for Windows, Mac, and Linux to be used to create and publish.
https://rpg-paper-maker.com/ 

8: Redot is a fork of Godot, it is pretty similar to Godot, lightweight, easy to use, open source and free. 
Given as such, it also has Godot’s negatives as well, that being mainly how lightweight it is, but considering everything else is a very good engine if starting out, or if used to Godot.
https://www.redotengine.org/ 

9: Pyglet is a python library used to develop games for windows, linux, etc for free. 
Because it is based specifically around Python it is relatively easy to use and learn and it is under the BSD open source project, allowing users to publish with little to no restrictions.
Only con I could find would be any issues regarding python itself since it is based entirely on that, while I am not completely sure about issues python might have as a language in general, python being so simple could lead to issues when doing more complex tasks, but again I am unsure.
https://pyglet.org/ 

10: Unigine is a 3D game engine primarily targeted at artists but is also used by the German Aerospace Center. 
This engine goes pretty in depth so if you know what you’re doing or have experience with 3D engines this should feel right at home. 
A con however is that this is a rather heavy engine and may not be the best for those just starting out.
https://unigine.com/
